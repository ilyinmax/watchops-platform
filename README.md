# WatchOps Platform

Практический учебный проект для последовательного изучения DevOps — от Linux и сетей до CI/CD, Infrastructure as Code, Kubernetes и observability.

## Структура

- `docs/` — roadmap и проектная документация;
- `labs/` — результаты отдельных учебных тем;
- `watchops/` — исходный код и конфигурация WatchOps;
- `incidents/` — разборы диагностических поломок и инцидентов.

## Обучение

Каждая тема проходит в отдельном чате ChatGPT согласно файлу [`docs/ROADMAP.md`](docs/ROADMAP.md).

Процесс темы:

1. необходимая теория;
2. управляемая практика;
3. самостоятельный босс;
4. диагностическая поломка;
5. фиксация результата в GitHub.
