# Тема 01 — Терминал, shell, пути, файлы и каталоги

## Практический результат

Создана файловая структура первой лаборатории и выполнена её реорганизация только через терминал Linux.

В ходе работы использовались создание каталогов и файлов, копирование, перемещение, переименование, поиск скрытых файлов, glob-шаблоны и безопасное удаление.

## Использованные команды

* `pwd` — показывает абсолютный путь текущего каталога.
* `ls` — показывает содержимое каталога.
* `ls -la` — показывает подробный список, включая скрытые файлы.
* `find` — ищет файлы и каталоги и позволяет просматривать структуру дерева.
* `mkdir` — создаёт каталог.
* `touch` — создаёт пустой файл.
* `cp` — копирует файл или каталог.
* `mv` — перемещает или переименовывает файл или каталог.
* `rm` — удаляет файл.
* `rmdir` — удаляет только пустой каталог.

## Пути в Linux

* `/` — корневой каталог файловой системы Linux.
* `~` — домашний каталог текущего пользователя.
* `.` — текущий каталог.
* `..` — родительский каталог, находящийся на один уровень выше.

Абсолютный путь начинается от корневого каталога `/`.

Пример:

```text
/home/ilyin/projects/watchops-platform
```

Относительный путь определяется относительно текущего каталога.

Пример:

```text
config/watchops.conf
```

## Glob-шаблоны

Shell может раскрывать шаблоны имён файлов до запуска команды.

Основные шаблоны:

* `*` — любое количество символов;
* `?` — ровно один произвольный символ;
* `[12]` — один символ из указанного набора.

Например:

```bash
logs/*.log
```

раскрывается shell в список всех подходящих `.log`-файлов каталога `logs`.

Перед потенциально опасной массовой операцией шаблон можно сначала проверить:

```bash
printf '%s\n' logs/*.log
```

Это позволяет увидеть, какие именно файлы получит команда.

## Скрытые файлы

Файл, имя которого начинается с `.`, считается скрытым.

Например:

```text
.workspace-note
```

Обычный `ls` его не показывает, поэтому для поиска можно использовать:

```bash
ls -la
```

или:

```bash
find .
```

## Безопасное удаление

При удалении использовались конкретные пути к объектам вместо массовых шаблонов.

Перед удалением путь проверялся, например:

```bash
ls -ld temporary.tmp
```

Для пустых каталогов использовался `rmdir`, потому что он откажется выполнять удаление, если каталог содержит файлы.

В этой лаборатории не требовались `rm -r` и `rm -rf`, что снижает вероятность случайного удаления нужных данных.
